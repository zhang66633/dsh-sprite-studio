# 切片牢大 · dsh-sprite-studio

> A canvas workspace for sprite sheets inside [DeepSeek Harness](https://github.com/deepseek-ai/dsh) —
> drop sheets in, slice them, matte them, compose characters, export atlases.
> 画布式的精灵图工作台，DSH 插件。

左侧栏点一下图标就进来：把精灵图拖进画布即存，右侧直接做切分、抠图、拼角色、导出。
全部图像处理都在浏览器 Canvas 里跑，数据落在本机 IndexedDB。

## 能力

| 分组 | 做什么 |
| --- | --- |
| **画布** | 拖入 / `Ctrl+V` 粘贴 / 选文件导入；拖动、框选、多选、撤销 60 步；`⌘/Ctrl+滚轮` 以光标为锚点缩放，中键任意位置平移 |
| **切分** | ① 网格（行/列/外距/间隔，画布上实时叠格子并编号）② 尺寸预设：LPC 64 / 图集 32 / Kenney 18 / 16 ③ LPC 动作预设：突刺/行走/挥砍/坐下，自动定位到 4 行并四向命名 ④ alpha 连通域自动检测 ⑤ 按行扫描（手拼表：先切行、再逐行切帧，每行可单独填帧数）⑥ **一键切成帧**（64 格 + 四向命名 + 跳空 + 立刻切） |
| **抠图** | 边框众数自动采样背景色或吸管取色；「边缘连通」漫水保主体内部同色块，「全局色差」清所有近似色；容差、边缘柔化、裁透明边，双图实时预览 |
| **生成背景** | 程序化**可无缝平铺**底图：两层周期噪声 + 9 种混合 + 后处理 + 7 套多段色带 + 通道打包 + **域扭曲**；3×3 平铺与横向滚动验收 |
| **特效** | 12 个程序化特效：弧形斩击 / 爆炸放射 / 光晕圆环 / 速度线 / 拖尾 / 月晕 / 冲击闪光 / 能量球 / 星云 / 微光星场 / 冲击波 / 烟尘。形状由参数算，颜色交给色带，透明度按强度分级 |
| **LPC 素材库** | 上游 **19 类 1066 件**部件的路径清单（只存路径，点击时按需取原文件），缩略图网格 + 跨类别搜索；**双层部件**（马尾/披风等 fg+bg）成对取回 |
| **角色合成** | 选中若干部件 → 按部位**自动排层**（身体/下装/鞋/上衣/护肩/护臂/头发后层/头/项链/五官/眼睛/胡子/头发/帽子/盾牌/武器）→ 合成为一张表；支持偏移、隐藏、六向对齐、等距分布；**角色配方**可命名存/取回 |
| **变换** | 水平/垂直翻转、顺/逆时针 90°、像素级 ×2/÷2、裁透明边、调色（色相/饱和度/亮度，从原图重算可还原） |
| **动画** | 选中 ≥2 张按名字自然序播放；**单张整表**也能按 64 网格直接拆帧预览（不必先切）；8/12/24 fps、洋葱皮、帧条跳帧 |
| **导出** | ZIP（每张一个 PNG + `manifest.json`）；逐张下载；**图集合成**（atlas.png + Aseprite 字段的 atlas.json，含 pivot 锚点）；导出倍率 ×1/×2/×4；工程 JSON 带图片本体，可换机器继续 |

右侧检查器默认全部收起，选中图片不会把面板撑开；开过哪几个板块会被记住。顶部有一排快捷入口，点一下展开并滚过去。

## 安装

本仓库声明了 `dsh.bundle`（`cordis.patch.yml`）与 `dsh.client`（`platform: web`），是标准 DSH bundle。

```text
plugin_manager install_bundle  target="<本仓库路径或地址>"
```

装完刷新一次窗口（客户端模块不会热替换），左侧栏就会出现「切片牢大」入口。

## 快捷键

`⌘` 与 `Ctrl` 等价。焦点在输入框里时键盘让位给输入框。

| 操作 | 按键 |
| --- | --- |
| 撤销 / 重做 | `Ctrl/⌘ + Z` / `Ctrl/⌘ + Shift + Z`（`Ctrl+Y` 也行） |
| 复制选中 / 全选 / 删除 | `Ctrl/⌘ + C` / `Ctrl/⌘ + A` / `Delete`·`Backspace` |
| 取消选择（并收起切分预览） | `Esc` |
| 缩放重置 100% | `Ctrl/⌘ + 0` |
| 粘贴剪贴板里的图 | `Ctrl/⌘ + V` |
| 重新生成 / 换种子（生成面板打开时） | `Space` / `R` |

## 数据在哪

- IndexedDB 库名 `dsh-sprite-studio`（`sprites` + `kv` 两个 store），只在本机。
- 换机器：用「画布 → 导出工程」拿 `.json`，再在新环境导入（里面含 dataURL，文件会比较大）。

## 已知限制

- **不生成 GIF**，也没有逐像素手绘编辑器。
- 界面文案只有中文（插件市场里的标题/描述有 zh/en 两份）。
- 撤销历史只在内存里，刷新后从零算起（内容本身已落库）；镜头平移缩放不进历史。
- 大图（>4096px）的自动检测会明显变慢（逐像素漫水，纯 JS）。
- LPC 库只提供**路径**，取文件依赖上游仓库可访问；取不到的会记进「失败清单」可一键复制。
