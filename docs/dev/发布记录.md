### 发布过程中的两个坑

1. **`git push` 在这台机器上不通**：`github.com:443` 连不上（`Connection was reset` / 超时），
   但 `gh` 走的 API 通道是好的。所以改用 GitHub Data API 推：
   `git/blobs` → `git/trees` → `git/commits` → 更新 `refs/heads/master`。
2. **空仓库不接受 `git/blobs`**（HTTP 409 "Git Repository is empty"）。
   必须先通过 Contents API `PUT` 一个文件落下第一个提交，之后 Git Data API 才可用。
